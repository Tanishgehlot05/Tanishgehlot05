## Projects

**[CF Companion](https://github.com/Tanishgehlot05/cf-companion)**
A GNOME Shell extension that shows upcoming and live Codeforces contests in the top bar, with countdowns, reminders, starred contests, your profile and friends, and five colour themes.
`JavaScript` · `GNOME Shell 46` · [Download v2.0.0](https://github.com/Tanishgehlot05/cf-companion/releases/tag/v2.0.0)

**[BloomFusion](https://github.com/Tanishgehlot05/BloomFusion)**
A small key-value database I wrote to learn how a Bloom filter in front of a wide B-tree speeds up lookups, with a benchmark against `std::map` and `std::unordered_map`.
`C++`
